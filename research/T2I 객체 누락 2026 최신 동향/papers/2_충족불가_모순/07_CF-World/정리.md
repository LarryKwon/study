# Are Text-to-Image Models Inductivist Turkeys? A Counterfactual Benchmark for Causal Reasoning
- 저자/소속: Jiayi Lei, Yuandong Pu, Xingyu Han, Rongpeng Zhu, Jing Xu, Jinyao Wang, Zijian Zhou, Bin Fu, Yuewen Cao†, Yihao Liu†, Hongsheng Li† (Shanghai Jiao Tong Univ., Shanghai AI Laboratory, CUHK)

- 링크: https://arxiv.org/abs/2606.24548
- 읽은 범위: 본문 전체 + 부록 A–F(데이터시트, threshold 보정, 평가 프롬프트 전문, 정성 분석, 계산 자원, 한계) 모두 읽음
- 한 줄 요약: 같은 장면을 L1(사실), L2(법칙을 바꾸고 결과까지 명시), L3(법칙만 바꾸고 결과는 추론하게 함)의 3단계로 만든 1,091그룹 / 3,273 프롬프트 벤치마크다. 14개 T2I 모델 모두 L1→L2→L3로 갈수록 급락하며, 특히 **결과를 명시해 줘도(L2) prior로 회귀하는 "prior lock-in"**이 핵심 실패라고 보고한다. 방법은 제안하지 않는 진단 논문이다.

## 1) 미리 알아야 할 기본 개념

- **Inductivist turkey / Pearl's Ladder of Causation**: Russell의 칠면조는 관찰된 상관관계(1단계 Association)에만 의존해서, 전제가 바뀐 세계(2단계 Intervention, 3단계 Counterfactual)를 상상하지 못한다. 저자들은 T2I 모델이 시각-텍스트 동시출현 패턴만 학습한 칠면조인지 묻는다.
- **3-level progressive framework (논문 고유)**:
  - **L1 Factual**: 실세계 법칙대로(예: "실온의 물 한 병" → 액체). 기본 렌더링 능력을 확인한다.
  - **L2 Explicit Counterfactual**: 법칙을 바꾸고 시각적 결과도 명시한다("물의 녹는점이 100°C라면 실온의 물을 그려라. 이 경우 물은 얼음이어야 한다"). 추론이 필요 없으므로 **prior를 이기고 명시된 비전형 상태를 그릴 수 있는지**만 본다. 내 연구 관점에서는 "명시적 요구 vs 강한 prior"가 충돌하는 **상충 요구 상황**에 해당한다.
  - **L3 Implicit Counterfactual**: 법칙만 바꾸고 결과는 모델이 연역하게 한다.
- **Assessment Point**: 프롬프트마다 붙은 "결정적 시각 기준"(예: Water is ice). LLM이 생성하고 사람이 검수한다.
- **CF-Eval**: Gemini-3-Pro가 프롬프트별로 3개 차원의 질문을 생성하고, VLM(Qwen3-VL-235B 또는 Gemini-3-Pro)이 각 질문에 0–1 점수를 매긴다. 차원은 (1) Visual Integrity(가중치 2–3; 본문은 1–3), (2) Assessment Point(15; 본문은 12–16), (3) Logic Consistency(8; 본문은 7–9)다. 이미지 점수는 S = Σwᵢsᵢ / Σwᵢ다.
- **Sequential thresholding**: 같은 그룹의 S_L1 < 0.5이면 S_L2와 S_L3를 0으로 둔다. 사실 장면도 못 그리면 반사실 성공은 우연으로 간주한다는 취지다. 0.5는 인간 150장 라벨에서 정확도 94.0%, F1 0.93이 최대가 되는 값으로 보정했다(부록 Table 4: T=0.3/0.4/0.5/0.6/0.7 → 74.2/82.5/94.0/86.1/78.3%).
- **PRR (Prior Resistance Rate)** = √(E[S_L2] · E[S_L2]/E[S_L1]) = E[S_L2]/√E[S_L1]. 절대 점수와 L1 대비 비율의 기하평균이며, 낮으면 "concept lock-in"이다.
- **RRR (Reasoning Retention Rate)** = E[S_L3]/√E[S_L2]. L2→L3에서 추론으로 결과를 메우는 능력이다. (Table 2 수치로 검산하면 SANA: 0.36/√0.83 = 0.395 ≈ 0.40으로 일치한다.)
- **Decoupling (논문의 원인 프레임)**: 모델이 "법칙(rule)"과 "외형(attribute)"을 독립 변수로 분리하지 못하고 고빈도 패턴으로 묶어 저장한다는 가설이다. **De-nominalization**은 결과 서술의 명사(예: "ice")를 묘사구로 바꿔 어휘 단서의 prior 활성화를 피하는 조작이다.
- **LC-Mis (Zhao et al. ECCV'24, "Lost in Translation")**: 드물게 함께 나오는 개념 쌍에서 생기는 latent concept misalignment 벤치마크. 5.2절의 attribute decoupling 실험에서 rare pair 100개를 여기서 가져왔다.

## 2) 무엇을 문제로 보았나 (관찰한 증상 · 분석한 원인)

**문제의식**: 기존 reasoning 벤치마크(WISE, R2I-Bench, Commonsense-T2I, T2I-ReasonBench, GIR-Bench)는 관습적 시나리오라서 정답을 "기억된 고빈도 패턴"으로도 맞힐 수 있다. 기존 counterfactual 벤치마크(ELNP, LC-Mis)는 무관한 객체의 단순 결합이라 법칙에 대한 연역을 평가하지 못한다(Table 1).

**관찰한 증상 (Table 2, Fig. 4/7)**
- 모든 모델이 L1→L2→L3로 갈수록 급락한다. 오픈소스는 L1 0.66–0.88에서 L2 0.21–0.48, L3 0.11–0.29로 떨어진다.
- 예: "표면장력이 무한하다면 수영장을 걸어 들어가는 사람" → 대부분 모델이 L2에서 명시해 줘도 사람이 **물에 잠긴** 이미지를 생성한다(Fig. 7). 법칙은 텍스트에 있는데 결과는 prior 상태다.
- Logic Consistency 실패도 나타난다: 주체는 반사실로 그렸는데 주변 환경은 정상 물리로 되돌아가는 "logical fracture".
- **오픈소스와 폐쇄형의 격차**: Nano Banana Pro는 L2 0.67/0.76, L3 0.58/0.67(Qwen/Gemini 판정)이다. 오픈소스 최고는 FLUX.2-dev로 L2 0.42/0.48, L3 0.26/0.28이다.
- BAGEL → BAGEL-CoT(텍스트 CoT 추가)는 L2 0.29→0.43, L3 0.17→0.29(Qwen 판정)로 오른다. 저자들은 이를 "marginal"이라고 표현하지만 수치상으로는 오픈소스 중 큰 폭이다(내 해석).

**원인 분석 (저자 주장과 근거, 5장 / Table 3)**
1. **Rule decoupling** (추상 기호 198 프롬프트, 33개 규칙, 사실 1–2개와 반사실 4–5개, 예: 중력 방향을 좌/우/상으로 변경. Qwen3-30B가 질문을 만들고 Qwen3-VL-235B가 채점): 대부분 모델이 낮다(사실 0.19–0.61, 반사실 0.07–0.53). 사실 점수와 반사실 점수가 상관된다. 저자들은 "반사실 실패는 prior 위반만이 아니라 기호 규칙 표현·적용의 일반적 한계"라고 해석한다.
2. **Attribute decoupling** (LC-Mis rare pair 100개 vs Gemini가 만든 common pair): 사실 0.92–0.99, 반사실 0.80–0.90. 즉 지각적 재조합은 상대적으로 잘한다.
3. **De-nominalization** (L2의 결과 명사를 묘사구로 치환): 모든 모델이 +0.01~+0.09 개선된다. FLUX.2-dev가 +0.09로 가장 크다. 저자 결론은 "명사가 prior를 활성화하는 간섭이 측정 가능하게 존재하지만 주원인은 아니다"이다.
4. 종합 주장 (5.4절):
   - 속성 재조합보다 **고수준 규칙의 decoupling 실패가 지배적 병목**이다(attribute는 반사실에서 사실 대비 81% 이상 유지되지만 rule은 최저 0.37).
   - "Two regimes": diffusion은 얕은 어휘적 얽힘이라 rephrasing에 반응하고, unified 모델은 깊은 의미적 얽힘이라 반응하지 않는다.
   - "Paradox": L1이 강한 모델(Qwen-Image)이 오히려 PRR이 낮으므로 강한 prior가 반사실을 방해한다.

## 3) 방법 (Method) — 벤치마크 구성·채점

- **규모**: 1,091 시나리오 × 3 level = 3,273 프롬프트. 분야는 5개다: Physics(고전역학, 광학, 열역학, 천문, 전자기), Biology, Chemistry, Geography, Sociology. 지식 난이도는 중학교 수준으로 통제해서, 실패가 전문지식 부족이 아니라 반사실 규칙 이해·적용 실패를 반영하도록 했다. (Fig. 2a 분야별 개수는 PDF 텍스트 추출이 깨져 정확히 확인하지 못함. Chemistry 173, Geography 25, Sociology 22, Astronomy 75, Electromagnetism 55 등의 라벨은 보이지만 합계가 1,091과 맞지 않아 인용을 보류함.)
- **생성 파이프라인**: 사람이 기본 원리를 선정한다 → LLM(Gemini-3-Pro)이 L1/L2/L3 프롬프트와 assessment point를 생성한다 → "전문가" 인간 검수로 필터링한다. 기준은 Visual Unambiguity, Logical Deduction Requirement, Safety, Scientific Validity다. 검수자 수, 탈락률, 일치도는 보고되지 않았다.
- **평가 질문 생성 프롬프트(부록 C.2)**: Assessment Point는 "단일 질문으로 합칠 것", "0.5점을 극도로 받기 어렵게"라고 지시한다. L1의 D3는 "minor flaw=0.5". L2/L3의 D3는 "Zero Tolerance for Logical Fractures"로, 환경이 정상 물리로 돌아가면 0이다.
- **판정자 보정(부록 C.1, 중요)**: Qwen이 반사실에서 관대한 경향(정상 객체에 높은 점수)을 보여서, **Qwen에게는 L2/L3에서만 "Strict, Adversarial Judge" persona를 주고** L1에서는 "objective and balanced" persona를 준다. Gemini도 L1은 "core concept을 전달하면 1.0, 완전히 무관할 때만 0.0"으로 관대하게, L2/L3는 "AI는 흔히 정상 객체로 회귀하니 주의"로 엄격하게 지시한다.
- **평가 모델 14종**: 오픈소스는 SANA 1.5, Janus-Pro-7B, Show-o2, Z-image, Lumina-DiMOO, BAGEL, BAGEL-CoT, OmniGen2, FLUX.2-dev, Qwen-Image. 폐쇄형은 Nano Banana, Nano Banana Pro, GPT-Image-1.5, Seedream 5.0. 판정자는 Qwen3-VL-235B와 Gemini-3-Pro 둘이다.
- **비용**: A100 80GB 16장 기준 오픈소스 모델당 생성 약 2시간, Qwen 채점 2–3시간. 폐쇄형은 API를 썼다. 프롬프트당 이미지 수나 seed 수는 명시되지 않았다(1장으로 추정).

## 5) Challenge를 걸 부분

**(a) 평가 설계 — L1→L2 급락의 일부가 판정 프롬프트 비대칭에서 나왔을 가능성 (가장 큰 약점, 내 비판)**
- L1과 L2/L3는 서로 다른 판정 persona와 기준으로 채점된다(부록 C.1–C.4). L1은 "core concept 전달 시 1.0"으로 관대하고, L2/L3는 "adversarial, 모호하면 0.5나 0.0", D3는 zero-tolerance다. 질문 생성 단계에서도 "0.5를 극도로 받기 어렵게"라고 지시한다. 그러니 **같은 이미지 품질이라도 L2/L3 점수가 낮게 나오도록 설계**되어 있다. 핵심 결론인 "sharp degradation"의 크기는 이 비대칭과 분리되지 않는다. 대칭 판정(같은 persona와 기준)으로 다시 채점하는 ablation이 필요하다.
- Sequential thresholding(S_L1<0.5면 L2/L3=0)은 L1 실패를 L2/L3 점수에 그대로 전파한다. L2 하락에 L1 실패분이 섞이므로 "prior lock-in"과 "기본 렌더링 실패"가 혼재한다.
- **Gemini 계열 자기 선호 위험**: Gemini-3-Pro가 데이터셋 생성, 평가 질문 생성, 판정을 모두 맡는데, 최고 성능 모델이 Nano Banana Pro(Gemini 이미지 모델)다. Gemini 판정에서 Nano Banana Pro의 L2는 0.76인 반면 Qwen 판정에서는 0.67로, Gemini 판정 쪽이 더 높다. Human 일치도 검증은 2개 모델에 히스토그램만 제시하고 상관이나 κ, 수준별(L1/L2/L3) 분해가 없다.
- seed 수, 표준편차, 유의성 검정이 없다. 모델 간 0.01–0.05 차이 해석은 근거가 약하다.

**(b) 분석 결론의 과잉 일반화 — 내 비판**
- **"Two regimes" 이분법은 자기 표(Table 3)와 맞지 않는다.** diffusion 계열인 SANA(+0.01)와 Qwen-Image(+0.02)는 de-nominalization 이득이 작고, unified인 Show-o2(+0.05)는 Z-image와 같다. diffusion "+0.05~+0.09"라는 서술은 FLUX.2와 Z-image만 고른 것이다. 실제로는 모델별 차이이지 계열 간 분리가 아니다.
- **"Paradox(L1 강할수록 PRR 낮음)"는 지표 정의의 산물에 가깝다.** PRR = L2/√L1이므로 L1이 높으면 자동으로 PRR이 깎인다. Qwen-Image(L1 0.84, L2 0.35)와 SANA(0.83, 0.36)의 PRR 차이는 L2 0.01 차이일 뿐이다. 실제로 L1 상위인 BAGEL-CoT와 FLUX.2는 PRR도 상위권이라 역상관 근거가 없다.
- **Rule decoupling 결과는 "prior lock-in" 서사와 긴장 관계다.** FLUX.2(0.53→0.52), Qwen-Image(0.40→0.40), SANA(0.31→0.30)는 사실과 반사실의 차이가 거의 없다. 이는 "반사실이라서" 실패한다기보다 **기호 규칙 렌더링 자체가 약하다**는 뜻이다. 저자도 일부 인정하지만, 초록과 결론은 여전히 "prior에 기본 회귀"를 주원인으로 서술한다.
- "Asymmetric decoupling(attribute > rule)"은 서로 다른 프롬프트 셋, 질문, 판정 기준으로 얻은 절대값을 비교한 것이라 비교 가능성이 약하다.
- L2 프롬프트는 L1보다 훨씬 길고 법칙 문장, 결과 문장, 원래 객체 명사가 함께 들어 있다. 따라서 L2 실패에는 **프롬프트 길이와 constraint 수 증가로 인한 누락**이 섞여 있을 수 있는데 통제하지 않았다(길이를 맞춘 대조 프롬프트가 없음). 내 연구 관점에서는 이 점이 오히려 흥미롭다.

**(c) 내 관심사와의 연결**
- L2 실패는 "명시적으로 요청한 상태(얼음)를 prior 상태(액체)로 덮어쓰는 것"이다. 즉 **요구된 속성·상태의 누락이 prior 대안으로 치환된 것**이며, 상충 요구(텍스트 명시 vs 학습 prior)에서 모델이 prior를 선택하는 해소 행동이다. 다만 CF-World는 연속 점수 하나로 뭉쳐서 **어떤 해소 행동(prior 선택 / 혼합 / 주체만 바뀌고 환경은 회귀 / 객체 자체 누락)인지 분해하지 않는다**.

**후속 연구 아이디어**
1. **L2 실패를 해소 행동 taxonomy로 재라벨링**: CF-World L2 이미지에 VLM과 인간 라벨로 {명시 상태 충족, prior 상태로 회귀, hybrid(부분 얼음/부분 물), 주체 반사실 + 환경 회귀(logical fracture), 대상 객체 자체 누락, 제3의 상태} 분포를 매긴다. 모델별·분야별 "해소 프로파일"을 만든다. 판정 비대칭 문제도 이 범주형 라벨링으로 우회할 수 있다.
2. **"부하(load) 하에서의 prior 회귀" 실험**: L2 프롬프트를 고정하고 무관한 객체 묘사 k개(0, 5, 10, 20)를 덧붙여 길이와 밀도를 늘린다. 가설은 "constraint가 많아질수록 비전형 요구가 먼저 누락되고 prior 상태로 회귀한다"이다. 결과 문장의 위치(앞/뒤)와 명사·묘사구 형태도 교차 조작한다. 긴 프롬프트 누락 연구와 상충 요구 연구를 한 실험에서 잇는 설계다.
3. **L3 = L2 + 추론인가?**: LLM으로 L3를 L2 형태로 확장(결과를 명시)한 뒤 생성해서, 이 점수가 원래 L2와 같으면 "추론 병목"이 아니라 "렌더링/prior 병목"임을 보인다. BAGEL-CoT의 +0.14(L2) 상승은 텍스트 측 확장의 효과를 시사하므로, 병목이 어디인지 정량적으로 가를 수 있다.
4. **Training-free 해소 기법 이식 실험**: 논문은 방법이 없다. SAP식 stage-aware proxy(초기에는 결과 상태의 형태가 비슷한 대체물, 예: "a block of glass" → "ice")와 de-nominalization, negative prompt(VL-DNP)를 L2에 적용해 PRR을 얼마나 회복하는지 측정한다. "prompt 수준 개입이 diffusion에는 통하고 unified에는 안 통한다"는 저자 가설도 직접 검증할 수 있다.
5. **판정 대칭화 재평가**: 모든 level을 같은 persona와 기준으로, 판정자 2종 + 사람 소표본으로 다시 채점한다. L1→L2 하락 중 판정 설계 기여분을 분리하는 작은 replication이며, 짧은 workshop 논문 하나로 충분한 분량이다.
