- 한 줄 요약: SoftREPA처럼 대조(InfoNCE) 손실로 soft text token을 학습하면 음성 쌍의 denoising 오차가 끝없이 커질 수 있다. 저자들은 이것이 과잉 계수와 반복의 원인이라고 본다. 그래서 정렬 신호를 Plackett–Luce 선호 모델로 정규화하고, 이를 score-matching의 목표(target noise)에 직접 더하는 방식으로 바꿨다. 양성과 음성에는 각각 별도의 soft token(ψ⁺/ψ⁻)을 둔다. 그 결과 SD3의 GenEval Counting이 SoftREPA 0.29에서 0.64로 회복되었다.

## 1) 미리 알아야 할 기본 개념

- **Score matching / ε-prediction**: 확산 모델은 노이즈 낀 xₜ에서 노이즈 ε를 예측하도록 학습한다(‖ε_θ(xₜ,t,c) − ε‖²). 이 예측은 조건부 score ∇log p(xₜ|c)와 비례 관계에 있다. 그래서 학습 목표의 ε를 다른 값으로 바꾸면, 모델이 따라갈 목표 분포 자체가 바뀐다. AGSM의 핵심이 바로 이 "target score를 바꿔서 학습"하는 것이다.
- **Flow matching / rectified flow (SD3)**: SD3는 ε 대신 velocity v를 예측한다. 부록 D(Eq. 16, 51)에서 같은 아이디어를 v에 대해 다시 유도한다.
- **CFG (classifier-free guidance)**: 조건부 예측과 무조건부 예측을 외삽해 p(x|c)·p(c|x)^w 쪽으로 샘플을 기울이는 기법이다. 논문은 자기 방법의 tilted 분포(Eq. 9)가 CFG와 같은 구조라고 설명한다. 음성 쪽 tilting은 negative prompt와 비슷한 "반발항"이다.
- **Soft (text) token / prompt tuning**: 백본은 얼린 채, 텍스트 임베딩 열에 학습 가능한 벡터 몇 개를 덧붙여 학습한다. 학습 파라미터는 약 1M 수준이다. SD1.5/SDXL에서는 UNet의 Down/Middle 블록에, SD3에서는 상위 5개 transformer 층에 넣는다.
- **SoftREPA (Lee et al., 2025a, arXiv 2503.08250, 같은 연구실)**: (x,c)의 유사도를 exp(−E‖ε_θ(xₜ,t,c,s) − ε‖²/τ(t))로 정의한다(Eq. 1). 미니배치의 다른 캡션을 음성으로 두고 InfoNCE(Eq. 2)로 soft token s를 학습한다. "맞는 캡션일 때 denoising 오차는 작고, 틀린 캡션일 때는 크게" 만드는 방식이다. REPA처럼 표현 정렬을 노린 reward-free 사후학습이다.
- **Bradley–Terry(BT)와 Plackett–Luce(PL)**: BT는 두 후보 중 무엇이 선호되는지를 σ(r₁−r₂)로 모델링한다. PL은 이를 여러 후보로 일반화해 softmax(r)로 쓴다(Eq. 7). 음성이 1개뿐이면 PL은 BT와 같다.
- **Diffusion-DPO / DSPO**: Diffusion-DPO는 선호 쌍에서 implicit reward(현재 모델과 참조 모델의 log 비율)를 써서 학습한다. DSPO는 선호 확률의 gradient를 target score에 더하는 score-level 선호 최적화다(Eq. 4–6). AGSM은 DSPO의 틀을 쓰되, 외부 선호 레이블 대신 모델 내부의 denoising 오차를 reward로 쓴다.
- **논문 고유 용어**
  - **implicit alignment reward** r(xₜ,c) = −(A(t)/2)‖ε_θ^{ψ̂}(xₜ,t,c) − ε‖² (Eq. 14). denoising 오차가 작을수록 정렬도가 높다고 본다. ψ̂는 EMA로 갱신하는 soft token이다.
  - **D⁺/D⁻**: 이미지와 자기 캡션의 쌍이 D⁺(z=1), 배치 안 다른 캡션과의 쌍이 D⁻(z=0)다.
  - **Δψ̂** = ε^{ψ̂}(xₜ,c) − Σᵢ wᵢ ε^{ψ̂}(xₜ,cᵢ): "현재 캡션 예측 − 후보 캡션 예측들의 PL 가중평균". 정렬 방향을 가리키는 대조 신호다.
- **GenEval**: 객체 검출기(Mask2Former)로 Single/Two object, Counting, Colors, Position, Color attribution을 채점한다. Counting은 "요청한 클래스의 검출 개수가 정확히 N인가"만 본다. 그래서 과잉인지 부족인지 방향은 구분하지 않고, 요청하지 않은 다른 클래스는 보지 않는다.

## 2) 무엇을 문제로 보았나

**관찰한 증상 (논문 주장)**
- SoftREPA는 GenEval 전체 점수를 SD3 0.68에서 0.70으로 올린다. 하지만 **Counting은 0.56에서 0.29로 반토막**이 난다(Table 1). 대신 Two object(0.86→0.95), Colors(0.85→0.92), Color attr(0.55→0.68)는 오른다.
- 정성적으로는 "객체 반복(repetition)"과 "과잉 계수(over-counting)"가 나타난다. 같은 물체가 여러 번 그려지는 식이다(Fig. 1, Fig. 3).
- 편집(PIE-Bench)에서는 SoftREPA가 over-edit이나 아티팩트를 만들어 원본 구조를 깨뜨린다(Fig. 6).
- 학습이 길어질수록 SoftREPA의 검증 ImageReward는 초반에 최고점을 찍은 뒤 크게 떨어진다. 그동안 학습 loss는 계속 줄어든다. 이는 과최적화이며, 휴리스틱한 early stopping이 필요하다는 뜻이다(Fig. 4).

**원인 분석 (저자 가설)**
- Eq. 1의 유사도는 denoising 오차에 대해 단조 감소한다. 그래서 InfoNCE를 최소화하면 양성 오차는 줄고, **음성 쌍 cⱼ의 오차 ‖ε_θ(xₜ,t,cⱼ,s) − ε‖²는 커지는 방향**으로 gradient가 흐른다(§3 도입).
- 이 음성 쪽 오차에는 상한이 없다. 그래서 soft token이 diffusion manifold 밖(off-manifold) 영역을 표현하도록 밀려난다. 저자들은 이것이 반복·과잉 계수·의미 비일관성으로 나타난다고 주장한다.
- 근거 실험은 ① GenEval Counting 붕괴(Table 1), ② 학습 동역학의 열화(Fig. 4), ③ 정성 예시(Fig. 3)다. "off-manifold"를 직접 측정한 실험(예: 음성 오차 크기 추적, 생성물의 객체 수 분포)은 없다. 즉 인과는 주장 수준이다.

## 3) 방법 (Method)

**핵심 아이디어**: "음성은 밀어낸다"는 대조 목표를, "양성/음성 각각에 정규화된 유한 크기의 가이던스를 target에 더한다"는 score-matching 목표로 바꾼다.

1. **PL 정렬 확률** (Eq. 7): p(z=1|xₜ,c) = exp r(xₜ,c) / Σᵢ exp r(xₜ,cᵢ). r는 모델 자신의 denoising 오차에서 온 implicit reward다(Eq. 8, 14).
2. **Tilted 목표 분포** (Eq. 9):
   - 양성: p⁺ ∝ p(xₜ|c)·p(z=1|xₜ,c)^{γ⁺}
   - 음성: p⁻ ∝ p(xₜ|c)·p(z=1|xₜ,c)^{−γ⁻}
   - 음성 쪽은 Bayes적으로 정확한 p(z=0|·) 대신 p(z=1)^{−γ⁻}를 surrogate로 쓴다. 저자들은 두 gradient의 방향이 같고 양의 스칼라 배만 다르다고 주장한다(부록 A).
3. **새 target score** (Eq. 11): ∇log p̃ = ∇log p(xₜ|c) + γ_z ∇log p(z=1|xₜ,c). 여기서 γ_z = γ⁺(양성), −γ⁻(음성)이다. PL의 gradient는 ∇r(c) − Σwᵢ∇r(cᵢ) 형태가 된다(Eq. 13).
4. **최종 손실** (Eq. 15/17, Algorithm 1). 배치 B개 이미지 × B개 캡션의 모든 쌍에 같은 t와 ε를 쓴다.
   - wᵢⱼ = softmaxⱼ(−‖ε_ema^{(i,j)} − ε‖²)
   - Δ^{(i,j)} = ε_ema^{(i,j)} − Σₖ wᵢₖ ε_ema^{(i,k)}
   - target: i=j이면 ε + γ⁺Ã(t)Δ, i≠j이면 ε − γ⁻Ã(t)Δ
   - 손실: ‖ε_pred − ε_tgt‖². 양성 쌍의 예측은 ψ⁺, 음성 쌍의 예측은 ψ⁻로 계산한다.
   - 정렬 신호(Δ)는 EMA 토큰 ψ̂로 계산해 안정화한다.
5. **안정성 논거** (Eq. 18): 보정항의 노름은 ‖∇r(c)‖ + Σwᵢ‖∇r(cᵢ)‖로 위에서 막힌다. 그래서 SoftREPA처럼 음성 오차를 키우는 방향의 하강이 생기지 않는다는 주장이다. 정합 후보가 PL에서 지배적이면 Δ가 0에 가까워져 일반 denoising 목표로 돌아간다.
6. **Dual-token**: ψ⁺와 ψ⁻를 분리하는 이유는, 하나의 토큰이 "끌어당김"과 "밀어냄"을 동시에 배우다가 생성 품질이 망가지는 것을 막기 위해서다. **샘플링 때는 ψ⁻를 버리고**, 조건부와 무조건부 예측 모두에 ψ⁺만 쓴다.

**학습/비용/하이퍼파라미터** (§4, 부록 G Table 11)
- 데이터: COCO-train. 배치 16(양성 1 : 음성 3). lr 1e-3, wd 1e-4, AdamW, CosineAnnealingWarmRestarts.
- iteration: SD1.5와 SD3는 100k, **SDXL은 1,000**이다(이유는 설명하지 않는다). 하드웨어는 A100 2장.
- 토큰 수: SD1.5/SDXL은 8개(양성 4, 음성 4). SD3는 상위 5층에 8개. 학습 파라미터는 1.8M(SoftREPA는 0.9M).
- γ⁺/γ⁻: SD1.5/SDXL은 (1, 1), SD3는 (1, 0.1). λₜ는 Ã(t)=1이 되도록 정한다.
- 학습 중 한 스텝마다 B×B 쌍에 대해 EMA 예측과 학습 예측을 모두 계산해야 한다. 추론 비용은 soft token 몇 개를 추가하는 정도라 거의 0이다.

## 5) Challenge를 걸 부분

**(A) 주장과 수치의 프레이밍**
1. **"counting +35%"는 SoftREPA가 만든 손상을 복구한 폭이다.** base 대비 개선은 +0.08이고, RankDPO(0.72)보다 낮다. 초록만 읽으면 base 대비 개선처럼 보인다.
2. **"SoftREPA와 대등하다"는 주장은 관대하다.** 부록 Table 8에서 선호 3지표는 모든 백본에서 SoftREPA가 앞선다. AGSM이 이기는 것은 FID와 CLIP이고, GenEval 전체 점수(0.72 vs 0.70)다. 본문 Table 1에서 COCO 행의 SoftREPA를 뺀 것도 독자의 판단을 흐린다.
3. **Recall과 precision의 맞교환이 드러나 있다.** SoftREPA는 Two object(0.95)와 Color 계열을 크게 올리는 대신 Counting을 망친다. AGSM은 Counting을 되찾는 대신 Two object(0.91), Colors(0.89), Color attr(0.64), Position(0.26, base 0.27보다도 낮음)을 일부 잃는다. "음성을 강하게 밀어내는" 신호가 **객체 존재(recall)는 끌어올리지만 개수 정밀도는 깨뜨린다**는 해석이 가능하다. 저자들은 이 맞교환을 논의하지 않는다.

**(B) 메커니즘 근거의 약점**
4. **과잉 계수를 직접 측정하지 않았다.** GenEval Counting 실패는 과잉과 부족을 구분하지 않는다. "over-counting"은 정성 예시(Fig. 1, 3)로만 뒷받침된다. 개수 오차의 부호 분포, 요청 외 객체 수, 반복 인스턴스 비율 같은 정량 지표가 없다.
5. **"off-manifold drift"를 측정하지 않았다.** 음성 쌍의 denoising 오차 궤적, soft token 임베딩의 노름이나 분포 이탈, 생성물의 FID 분해 같은 직접 증거가 없다. Fig. 4는 ImageReward 열화만 보여 준다.
6. **유계성 논거(Eq. 18)는 약하다.** 상한이 reward gradient 노름의 합이고, 그 노름 자체가 유계라는 보장은 없다. 부록 A의 surrogate p(z=1)^{−γ}와 Bayes형 p(z=0)은 방향만 같다. 스케일 1/p 대 1/(1−p)는 p가 0이나 1에 가까울 때 크게 다르다. 그래서 "Bayes-consistent"라는 표현은 과장이다.
7. **SoftREPA 비교가 통제되지 않았다.** SoftREPA는 공식 체크포인트를 썼는데, SD1.5/SDXL에서는 음성 7개·배치 64였고 early stopping 시점도 알 수 없다. AGSM은 배치 16이다. 과잉 계수가 "대조 목표 자체" 때문인지 "체크포인트 선택이나 과학습" 때문인지 분리되지 않는다. 같은 예산과 같은 음성 수로 SoftREPA를 다시 학습해 비교했어야 한다.
8. **Table 7(BT vs PL)은 사실상 음성 개수 ablation이다.** BT 행(29.67/21.52/27.13/25.31/24.76)은 Table 13의 배치 4(1:1) 행과 **수치가 완전히 같다.** 음성이 1개인 PL은 BT와 같으므로, "PL이 BT보다 낫다"는 결과는 "음성 3개가 1개보다 낫다"와 구분되지 않는다. 게다가 배치 64(1:7)에서는 오히려 성능이 떨어진다(32.32).

**(C) 실험 설계와 일반화**
9. **최신 MM-DiT와 긴 프롬프트 검증이 부족하다.** FLUX, SD3.5, Qwen-Image는 없다. UniGenBench++는 선호 점수로만 평가했다. 긴 프롬프트에서 객체별 누락률이나 정밀도는 측정하지 않았다.
10. **음성이 COCO 배치 안의 무작위 캡션이다.** 대부분 쉬운 음성이라, 개수 ±1이나 속성 교환 같은 hard negative를 다루지 못한다. 그래서 개수 정밀도를 직접 학습시키는 신호가 아니다.
11. **판정자가 편향되어 있다.** ImageReward, HPS, Pick은 "풍성한" 이미지를 선호한다. Table 5와 Fig. 8에서 ψ⁻ 샘플링이 "언급 안 된 배경을 지운다"는 이유로 불리하게 평가된 것이 그 예다. **요청 외 객체를 줄이는 관점에서는 오히려 바람직한 행동일 수 있다.**
12. **재현성 정보가 부족하다.** 시드 수와 분산을 보고하지 않는다. SDXL만 1,000 iteration인 이유가 없다. SD3 버전이 명시되지 않았다.

**(D) 사용자 관심사로 확장하는 후속 연구 아이디어**
1. **대조 정렬의 Recall–Precision 분해 연구**: SoftREPA, AGSM, Diffusion-DPO, RankDPO 각각에 대해 (i) 요청 객체 재현율, (ii) 개수 오차의 부호(과잉/부족), (iii) 요청 외 객체 수(ICO식 동시출현 객체, OverReal-Det)를 따로 잰다. 가설은 "음성 반발이 강할수록 recall은 오르고 precision은 떨어진다"이다. 기존 노트의 "누락을 고치는 처방이 추가를 만든다"는 우려를 정량적으로 검증하는 첫 연구가 될 수 있다.
2. **ψ⁻를 "요청 외 내용 억제기"로 재활용하기**: 저자들이 버린 "무조건부에 ψ⁻" 설정을 γ로 연속 조절한다. 그리고 선호 점수 대신 객체 단위 precision/recall로 Pareto 곡선을 그린다. 긴 프롬프트에서 "언급된 것만 그리기"와 "디테일 풍부함" 사이의 조절 노브로 쓸 수 있는지 확인한다.
3. **Hard-negative 설계로 누락과 상충을 표적 학습**: 음성을 무작위 캡션 대신 **최소 편집 캡션**으로 만든다. 예: 긴 프롬프트에서 한 절 삭제(누락 음성), 개수 ±1(계수 음성), 상충 속성으로 교체(충돌 음성). PL 가중치 w가 어떤 음성에 집중되는지 보면, 모델이 어떤 요구를 "구별하지 못하는지"를 진단할 수도 있다.
4. **절 위치별 효과 측정**: UniGenBench++, DetailMaster 같은 긴 프롬프트에서 앞·중간·뒤 절의 객체 존재율이 soft token 정렬로 어떻게 바뀌는지 잰다. soft token이 텍스트 시퀀스 끝에 붙는 구조라 위치 편향과 상호작용할 수 있다.
5. **과잉 계수의 발생 시점 진단**: Images Talk Back의 I2T 메시지 분석을 SoftREPA 생성 궤적에 적용한다. 반복 인스턴스가 초기 레이아웃 단계에서 생기는지 확인하고, 그렇다면 초기 스텝에만 ψ⁺를 적용하는 등 시간 창 제어로 막을 수 있는지 본다.
