                                                                                                      A BSTRACT

                                                   Multimodal diffusion transformers (MMDiTs) allow the evolving image to up-
                                                   date internal text representations through joint attention. These representations
                                                   then guide subsequent image updates, raising a question: does this feedback help
                                                   correct deviations from the prompt, or preserve them? We find that image-to-
                                                   text (I2T) feedback can preserve the objects and attributes already represented
                                                   in the evolving image, including errors. Transplanting I2T messages can res-
                                                   cue failures or disrupt successes. At matched intervention strengths, suppress-
                                                   ing the influence of I2T feedback improves generation, whereas opposite con-
                                                   trols degrade it. These findings motivate Semantic Feedback Guidance (SFG),
                                                   which suppresses the influence of I2T feedback by guiding away from an auxil-
                                                   iary branch that strengthens this feedback and weakens text-to-image condition-
                                                   ing. The in-place variant, iSFG, directly suppresses I2T feedback and strength-
                                                   ens text-to-image conditioning, requiring no extra model evaluations. Tempo-
                                                   ral interventions motivate running the SFG branch during the first 20% of im-
                                                   age sampling steps, requiring about 1.2× the base NFE without classifier-free
                                                   guidance (CFG). Experiments across three image-generation backbones show
                                                   gains in alignment and preference-model scores. On FLUX, adding SFG to
                                                   CFG raises GenEval from 0.6661 to 0.7479; on SD3.5M, iSFG adds +1.33
                                                   HPSv2.1 over CFG at zero extra NFE. The control also transfers to text-to-video
                                                   and image-to-video generation, improving VBench scores. Code is available at
                                                   https://github.com/yyc1215lll-creator/SFG.

1      I NTRODUCTION
Text prompts specify what an image generator should produce, but in MMDiTs, the internal text
stream also depends on what the model is drawing. Text queries read image keys and values before
later blocks use the updated text stream to condition the image. This image-to-text-to-image loop
underlies Stable Diffusion 3/3.5, FLUX, Qwen-Image, and HunyuanVideo (Esser et al., 2024; Black
Forest Labs, 2024; Wu et al., 2025; Kong et al., 2024). When the image departs from the prompt,
does this feedback correct the departure or preserve the existing image content? For the prompt “an
apple and an orange,” an image containing only an apple may write that incomplete scene back into
the text stream. Figure 2 illustrates the two possible effects: recovering the orange or reinforcing its
omission. The answer determines whether early errors are corrected or persist through sampling.

Existing analyses describe the image-to-text path as a register for image content and object identity,
or as the weaker cross-modal direction (Toker et al., 2025; Li et al., 2026; Shin et al., 2025). They
leave open how this content affects generation. We use image content to mean the objects and
attributes represented in the evolving image. Such content can conflict with the prompt; we test the
effect of preserving it by intervening on this path.
To address these questions, we intervene on the image-to-text path and measure its effect on gen-
eration. We find that this feedback can preserve image content that conflicts with the prompt, and
identify suppression as a useful direction. Specifically, we design two experiments to examine feed-
back content and local response direction. Message transplantation shows that feedback can rescue
failures or disrupt successes. At the same failed state, feedback suppression is more aligned with
the response to successful-message transplantation than with a norm-matched random control. Our
first ablation tests finite interventions and shows that suppression improves generation, whereas the
opposite control degrades it.
We construct a negative branch, the reference prediction that guidance extrapolates away from, by
increasing I2T feedback. Unlike SAG and PAG, which blur image regions or disrupt attention (Hong
et al., 2023; Ahn et al., 2024), this branch preserves the attention computation and gives the current
image more influence. Guiding away from it suppresses that influence. We call this control SFG-X.
A complementary control, SFG-S, weakens text-to-image conditioning in the same negative branch,
so guiding away strengthens conditioning. Together they form Semantic Feedback Guidance (SFG).
The in-place variant, iSFG, applies feedback suppression and stronger conditioning directly in the
conditional forward, with no extra model evaluations.
Early message transplants have the greatest effect on the final outcome, consistent with object layout
being largely fixed early in sampling, motivating a SFG guidance window covering the first 20% of
image sampling steps. This costs about 1.2× the base NFE without CFG, compared with 2× for an
auxiliary branch at every step. SFG corrections remain nearly orthogonal to CFG through sampling,
and the two methods combine effectively. Experiments on SD3M, SD3.5M, and FLUX show gains
in alignment, preference scores, and distribution quality; transfer to HunyuanVideo improves text-
to-video and image-to-video VBench scores over the base model and CFG.

2       F ROM MECHANISM ANALYSIS TO SIGNED GUIDANCE
2.1       BACKGROUND : GUIDANCE AND WRITABLE MMD I T STATES

CFG extrapolates between conditional and unconditional predictions; training-free self-guidance
extrapolates away from a perturbed prediction of the same model. The formulas and perturbation
choices are summarized in App. A. We choose the perturbation by measuring a native feedback path.
Writable MMDiT states. Generation integrates a learned velocity field backward from noise along
xt = (1−t)x0 +tϵ, with ϵ ∼ N (0, I) (Esser et al., 2024). The encoded prompt c = E(p) stays fixed.
Conventional cross-attention and deep fusion only let image queries read prompt-derived features
(Liu et al., 2024; Tang et al., 2025). MMDiT instead maintains image (i) and text (t) residual
streams, both querying concatenated image–text keys through a joint softmax:
                             Oi = Ai→i Vi + At→i Vt ,                                         Ot = At→t Vt + Ai→t Vi .                                (1)
                                            | {z }                                                           | {z }
                                                           Bt→i                                                       Bi→t

We call Bi→t the I2T message and Bt→i the text-to-image (T2I) message. The I2T message writes
image values into the text stream; the T2I message conditions the image on text. Later blocks can
read this updated text back into the image, closing a feedback loop. Each denoiser call resets text
from E(p), so the stream changes with depth and the current xt without persisting across timesteps.
We scale these messages after softmax, retaining joint normalization.

Message transplantation. We transplant the I2T message Bi→t . For success-to-failure transplan-
tation, we cache the message of the successful donor by step and block and insert it after softmax
and before output projection:

The donor mixing weight λ ranges from zero (retain) to one (fully replace). The prompt, seed,
sampler, initial latent, and other activations of the recipient remain unchanged. We measure rescue
among initially failed recipients and disruption among initially successful recipients: each counts
a change to the opposite outcome. Norm-matched random messages rarely change the outcome
(Figure 4).
We also test failed-donor and text-to-image transplants (Table 21); both yield lower rescue rates than
successful-donor image-to-text transplantation in the reported controls.
Direction and timing. On a separate fixed cohort of 400 success/failure pairs, we multiply the I2T
message by α in every joint block. At each unmodified failed state, Jt is the derivative of predicted
velocity with respect to this multiplier at α = 1; −Jt is the local response to reducing I2T feed-
back. Successful-donor transplantation changes the velocity by RtS , while a norm-matched random
message perturbation changes it by Rtrand (Figure 3b). The cosine gap over random compares their
cosine similarities with −Jt , subtracting the random-control value from the successful-donor value.
This gap is positive in both models across all time intervals (Figure 5). Transplanting during steps
1–8 of 40 recovers about two-thirds of the full-schedule rescues; late transplants rarely change the
outcome. Definitions and aggregation details are in App. F.2.
Appendix G uses object-omission probes in the internal text stream to test whether errors persist
once detected during sampling. Warnings usually persist without control; feedback suppression re-
duces this persistence and rescues many failures, with less frequent disruption of initially successful
outputs.

2.3   M ETHOD : SFG AND I SFG

SFG combines image-to-text feedback control (SFG-X) with text-to-image conditioning control
(SFG-S). It implements both through an auxiliary prediction and an extrapolation step. The in-
place variant, iSFG, applies the corresponding message scaling directly within conditional forward
pass.
Control targets and insertion point. In every joint-attention block, we scale the I2T and T2I mes-
sages after softmax and value aggregation, before output projection. TACA and Attend-and-Excite
strengthen T2I conditioning (Lv et al., 2025; Chefer et al., 2023); SFG-X controls the I2T message,
which neither method modifies. For a fixed block input, scaling preserves attention logits, joint
normalization, and within-modality terms. Model weights stay frozen, but each forward recomputes
activations, so earlier edits can affect later blocks through the updated text stream.
SFG: auxiliary-branch guidance. For edit strength u < 0, the auxiliary branch increases image-
to-text feedback and decreases text-to-image conditioning with tied magnitudes:
                                 Otpert (u) = At→t Vt + (1 − u)Bi→t ,
                                                                                                        (3)
                                 Oipert (u) = Ai→i Vi + (1 − |u|)Bt→i .
The first edit defines SFG-X, and the second defines SFG-S; SFG applies both in the same auxiliary
forward. To use either component alone, leave the other message at its original multiplier of one.
Setting u = 0 removes both edits. Text-to-image attenuation uses |u| ≤ 1; larger magnitudes reverse
the sign of that message.
We call an unmodified conditional forward at the current latent the clean branch. At the same xt , t,
and c, its prediction is vclean = vθ (xt , t, c); vpert is the auxiliary-branch prediction with the selected
message scaling. With guidance strength ω ≥ 0 and CFG scale s ≥ 1,
                             v̂ = vclean + ω (vclean − vpert )
                                                                                                        (4)
                                         + (s − 1) [vclean − vθ (xt , t, ∅)] .

Here u sets the message multipliers, ω is the SFG guidance scale, and s is the CFG scale. SFG-X
constructs its negative branch by strengthening I2T feedback (1 − u > 1), rather than degrading
the model. This strengthening of a native pathway takes the opposite approach to guidance methods
such as PAG (Ahn et al., 2024), SEG (Hong, 2024), and PG (Chen et al., 2026b), which construct
auxiliary branches by degrading the model. Guiding away suppresses this feedback, as motivated
by Section 2.2, while SFG-S strengthens conditioning by guiding away from its attenuation. The
sampler advances one trajectory using v̂. At s = 1, it omits the unconditional evaluation; otherwise,
that prediction remains unmodified.
iSFG: in-place control. iSFG edits the ordinary conditional forward directly:
                                                       OtiSFG = At→t Vt + (1 + γ)Bi→t ,
                                                                                                                                                                       (5)
                                                       OiiSFG = Ai→i Vi + (1 + γS )Bt→i .
The I2T multiplier is 1 + γ with γ < 0; the T2I multiplier is 1 + γS with γS > 0. Thus, u < 0
strengthens feedback in the negative branch, so guiding away suppresses its influence; γ < 0 applies
suppression in place. The component ablation attributes most of the gain of SFG to feedback control
(Section 3.3, Figure 7a). Let vip be the resulting conditional prediction. Without CFG, the sampler
uses vip directly; with CFG, it uses svip − (s − 1)vθ (xt , t, ∅). Only the conditional branch is edited.
These edit strengths are independent of ω; relations between matched branch and in-place controls
are given in App. A.
Sampling schedule and computational cost. SFG uses approximately 1.2K model evaluations
without CFG and 2.2K with CFG, activating its auxiliary branch during the first 20% of K image
sampling steps. iSFG adds no model evaluations and has minimal runtime overhead (App. D).

3.2     T RANSFER TO VIDEO GENERATION

Text-to-video generation. In both video tasks, SFG runs with cfg = 1 and requires no training.
For text-to-video, seven active steps of 25 require 32 branch predictions versus 50 for full-schedule
CFG and 39 for CFG limited to its first 14 steps. SFG reaches 84.25 on seven VBench dimensions,
exceeding all compared methods, including the base model (82.58; Table 4). Its +1.67 gain over the
base model is more than four times that of S2 -Guidance (+0.38), the other self-guidance baseline.
It leads in subject consistency and imaging quality (93.71 and 66.61, versus at most 93.08 and
64.94 under CFG). CFG retains higher background consistency and aesthetics; S2 -Guidance has the
highest dynamic degree. Unlike CFG, which lowers temporal flickering and motion smoothness
below the base model, SFG keeps both at or near base levels (98.18 and 99.36). It also raises
aesthetic quality from 50.88 to 56.00, recovering most of the gain from CFG.
Image-to-video generation. For image-to-video, reference-image and text tokens jointly form the
conditioning stream. SFG applies unchanged to this entire stream, suppressing feedback from the
evolving video and strengthening conditioning, and thus generalizes from text-only to multimodal

4               R ELATED W ORK

Negative branches and attention strengthening. CFG contrasts conditional and unconditional
predictions; training-free self-guidance extrapolates away from a perturbed model prediction (Ho &
Salimans, 2022; Chung et al., 2025; Hong et al., 2023; Ahn et al., 2024; Hong, 2024; Chen et al.,
2026a; Zhang et al., 2026; Chen et al., 2026b). SFG-X constructs this reference by strengthening
I2T feedback instead of degrading the model through blurred attention, identity maps, or skipped
blocks, using the measured response to select the sign. Limited-interval guidance restricts CFG to an
empirically chosen interval (Kynkäänniemi et al., 2024); our transplantation experiment measures
when feedback most affects the outcome. Attend-and-Excite amplifies neglected subject-token ac-
tivations (Chefer et al., 2023). TACA uses a timestep-aware temperature to rebalance cross-modal
attention and counter text-token imbalance (Lv et al., 2025). Both strengthen T2I conditioning, as
SFG-S does through guidance, but neither modifies how the image writes back into text. SFG-X
instead controls the I2T direction, where our intervention sweeps support suppressing feedback.
The two streams of an MMDiT. Studies of MMDiTs examine padding registers, multimodal cir-
cuits, prompt reinjection, and attention editing (Toker et al., 2025; Mazur et al., 2026; Ge et al.,
2026; Zhou et al., 2025; Shen et al., 2025; Yao et al., 2026). Toker et al. (2025) find image con-
tent in padding tokens; Li et al. (2026) find template tokens maintaining object identity; Shin et al.
(2025) identify I2T as the weaker cross-modal direction and build on T2I. We test how the stored
content affects generation and find that I2T feedback can preserve errors.


5               C ONCLUSION

We show that image-to-text feedback in MMDiTs can preserve image content that conflicts with
the prompt. Message transplantation, local response analysis, and matched interventions identify
feedback suppression as a useful control direction. Building on these findings, SFG guides away
from an auxiliary branch with stronger feedback and weaker text-to-image conditioning (about 1.2×
base NFE without CFG), while iSFG applies the corresponding controls directly with zero extra
NFE. Experiments across three image backbones demonstrate gains in alignment and preference

scores, both without and alongside CFG. The same control strategy improves the evaluated VBench
scores in text-to-video and image-to-video generation.

Guidance conventions.
CFG uses condition dropout during training and extrapolates between conditional and unconditional predic-
tions; AG instead contrasts well-trained and under-trained models (Ho & Salimans, 2022; Karras et al., 2024).
Training-free self-guidance perturbs one pretrained model:
                                         vCFG = vuncond + s(vclean − vuncond ),                                                                (6)
                                    vguide = vclean + ω(vclean − vpert ).                                 (7)
Here vclean is the clean-branch prediction, vuncond is the unconditional prediction, s is the CFG scale, and
vpert supplies the negative branch. SAG blurs image regions, PAG replaces attention with the identity, SEG
smooths attention, S2 -Guidance drops blocks, and SSG swaps extreme text tokens (Hong et al., 2023; Ahn
et al., 2024; Hong, 2024; Chen et al., 2026a; Zhang et al., 2026). We choose the perturbation by measuring a
native feedback path.
Local relation between SFG and iSFG. Let a = (aX , aS ) denote the I2T and T2I message multipliers:
(1 − u, 1 − |u|) in the SFG auxiliary branch, (1 + γ, 1 + γS ) in the iSFG conditional branch, and (α, 1) in the
local-response experiment. At fixed latent, time, and prompt, write the prediction as v(a). The clean branch
uses a0 = (1, 1), and the auxiliary branch uses a0 + h, where h = (dX , −dS ) and dX , dS ≥ 0. For a smooth
prediction, the first-order correction is
                             ω[v(a0 ) − v(a0 + h)] = −ωdX JX + ωdS JS + O(ω∥h∥2 ),                                                             (8)
where JX and JS are the derivatives with respect to the two message multipliers at a0 . SFG-X uses dS = 0,
and full SFG uses dX = dS = |u|. Setting the message multipliers to a0 − ωh gives the same first-order
correction in place. With CFG scale s > 0 and an unchanged unconditional branch, the matching conditional-
branch multipliers are a0 − (ω/s)h. This local relation motivates iSFG; the separately tuned methods need not
agree at finite strengths.
Connection to the measured response. The image-to-text derivative JX corresponds to J in the alignment
experiment. Appendix F.2 gives its centered-difference estimate and the successful-donor velocity response
RS . Reducing feedback moves locally along −J. A positive cosine gap over random indicates better rela-
tive alignment; it does not establish positive absolute cosine or improved final quality. Final outcomes and
intervention windows are evaluated by transplantation and the sign ablation, rather than inferred from the local
expansion. Probe definitions and their aggregation are given with the probe results in App. G.

D   I MPLEMENTATION DETAILS AND PSEUDOCODE

All experiments use one attention-processor patch on the public diffusers implementations of
SD3-Medium, SD3.5-Medium, and FLUX. The patch touches nothing but the fused scaled-dot-
product attention (SDPA) call of each joint-attention block:

# One MMDiT joint-attention block. X: image tokens, C: text tokens.
Qx, Kx, Vx = qkv_image(X)               # modality-specific projections
Qc, Kc, Vc = qkv_text(C)
Q, K, V    = concat(Qx,Qc), concat(Kx,Kc), concat(Vx,Vc)
O          = SDPA(Q, K, V)              # one joint softmax

# Cross-modal term of a chosen direction, at the SAME softmax weights:
# zero every value row outside the source modality, rerun SDPA on the
# target-query slice only.
B_i2t = SDPA(Q[text], K, V * mask(image)) # = A_{i->t} V_i
B_t2i = SDPA(Q[image], K, V * mask(text))   # = A_{t->i} V_t



                                                         17
O[text] += (a_X - 1) * B_i2t # I2T message multiplier a_X
O[image] += (a_S - 1) * B_t2i # T2I message multiplier a_S
# ... followed by the block’s usual output projections.

Because the mask only zeroes value rows, the softmax weights are exactly those of the unmodified
forward, and the added term is exactly Asource→target Vsource . Adding (aX −1)Bi→t or (aS −1)Bt→i
sets the corresponding message multiplier to aX or aS . The sampler-level combination is then
# Explicit SFG: use the guidance window selected for the task.
# K_act: e.g. 8/40 image steps or 7/25 T2V steps.
if step < K_act:
    v_clean = v_theta(x_t, t, c)
    # Full SFG (u < 0); SFG-X alone sets a_S = 1
    v_pert = v_theta(x_t, t, c, a_X=1-u, a_S=1-abs(u))
    v_hat   = v_clean + omega * (v_clean - v_pert) # + CFG if stacked
else:
    v_hat   = v_theta(x_t, t, c)       # ordinary forward, no extra NFE
# iSFG: gamma < 0 for I2T, gamma_S > 0 for T2I
v_ip = v_theta(x_t, t, c, a_X=1+gamma, a_S=1+gamma_S)
# Use v_ip directly, or combine with the unedited unconditional
# prediction through CFG; no auxiliary branch is evaluated.

The path edit is applied in every joint-attention block (layers=all). For explicit SFG, the nega-
tive branch is evaluated only during the selected guidance window, batched with the clean branch in
a single fused forward; the remaining steps run the ordinary forward with no extra evaluation. The
separate probe diagnostics in App. G use their explicitly specified windows, including full-schedule
guidance. The in-place iSFG edit runs at every step at zero extra NFE. A norm-clipping safeguard
on the residual (clip = min(1, τ ∥vθ (xt , t, c; 1)∥/∥∆∥)) exists in the implementation but is disabled
(τ =999) in the benchmark comparisons.

D.1    L OW- OVERHEAD I SFG IMPLEMENTATION
The optimized implementation folds the message multipliers into value aggregation, without a separate auxil-
iary Transformer branch or recomputation of the cross-modal messages above. Image queries use the original
image values and text values scaled by 1.20; text queries use the original text values and image values scaled
by 0.80. Both query groups attend to all keys with the original joint-softmax normalization, and their outputs
are concatenated in token order. The disjoint query groups cover the original joint attention without duplicating
its attention-score computation. Under CFG, only the conditional branch is edited. Remaining overhead comes
from value copies, scaling, and kernel dispatch.
We time SD3.5M on one A800 80GB GPU with BF16, 10242 resolution, 40 steps, CFG scale 7.5, and batch size
1. iSFG uses (γS , γ) = (+0.20, −0.20) in all joint blocks at all steps. After one warm-up per method, we alter-
nate three paired runs with matched prompts and seeds. Timing includes text encoding, denoising, and VAE de-
coding, excluding model loading and image writes. Both methods make 40 batched conditional/unconditional
Transformer calls. iSFG adds about 0.31 seconds per image (2.86%), with zero extra NFE.
