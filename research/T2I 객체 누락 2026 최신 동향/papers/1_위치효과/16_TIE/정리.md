## 1) 미리 알아야 할 기본 개념
- **CLIP text encoder의 causal attention**: SD 계열(SD1.x/SDXL/SD3.5)이 쓰는 CLIP-L/CLIP-G text encoder는 GPT식 causal mask를 쓴다. 그래서 token i는 j ≤ i인 token만 본다. 뒤에 나오는 token일수록 앞 token들의 정보가 섞여 들어간다. 이 논문은 이 점을 위치 편향(뒤쪽 개념 누락)의 구조적 원인 후보로 본다. 출력은 C = τ(P) ∈ R^{N×M}(N=77 고정 길이, padding/EOT 포함)이다.
- **Concept loss vs. concept confusion**: 논문이 실패를 두 종류로 나눈 것이다. *Concept loss*는 프롬프트의 개념(object 또는 attribute)이 이미지에서 사라지는 경우다. 여기에는 (a) attribute 누락과 (b) object 자체 누락이 있다. *Concept confusion*은 binding이 틀린 경우다. 여기에는 (c) attribute가 다른 object에 붙는 경우와 (d) 두 object가 섞여 하나가 되는 object mixture가 있다(Fig. 1).
- **Normalized token entropy (Eq. 1)**: token embedding c_i ∈ R^d의 각 좌표 절댓값을 정규화해 분포 p_{i,j} = |c_{i,j}| / Σ_k |c_{i,k}|를 만들고, 그 Shannon entropy를 log d로 나눈 값 H_i다. 크기(scale)에 무관하고, 정보가 많은 좌표에 퍼져 있을수록 커진다(effective dimensionality와 관련). 값은 0.95대에 몰려 있어서 차이가 0.001 단위다.
- **CLIP의 anisotropy와 공통 평균 방향 µ̂**: CLIP embedding들은 공통 평균 방향 µ̂ = µ/‖µ‖로 쏠려 있다(Ethayarajh 2019의 anisotropy). 논문은 token entropy가 c_i와 µ̂의 cosine 정렬도와 강하게 상관한다고 보고한다(CLIP-G Spearman |ρ| = 0.88). 해석하면 "entropy가 높다 = 다른 token과 구분되지 않는 공통 방향에 가깝다 = 개념 고유 정보가 약하다"는 뜻이다.
- **L0 attention score A_{i,j}**: CLIP text encoder **첫 번째 self-attention layer**에서 token i와 j 사이의 attention weight를 head별로 평균한 값이다. 여러 token으로 쪼개진 개념은 token별 값을 평균한다. 논문은 이 값을 attribute–object binding 강도를 나타내는 연속 신호로 쓴다.
- **SVD 기반 embedding 조작 / effective rank**: [attribute, object, EOT…] embedding을 열로 쌓은 행렬 X를 SVD하고 singular value를 재조정하면, 정보가 몇 개의 주요 방향에 모인다. Effective rank(erank)는 singular value 분포의 entropy로 정의하는 "실질 차원 수"다. 선행 연구 Li et al. 2024(Get What You Want, Not What You Don't)와 One-Prompt-One-Story가 이런 SVD 조작을 썼다.
- **EOT/padding token**: 프롬프트 뒤에 붙는 end-of-text/padding token에도 의미 정보가 실린다(Toker et al. 2025 "Padding Tone", Magnet). 그래서 AEP는 개념 token과 함께 EOT token도 증폭한다.
- **AEP / IEB / TIE**: AEP(Adaptive Embedding Preservation)는 concept loss를 막는 entropy-aware SVD 증폭이다. IEB(Interpolation–Extrapolation Binding)는 concept confusion을 막는 L0-attention 기반 embedding 당기기/밀기다. 둘을 합친 것이 TIE다.
- **BLIP-VQA (T2I-CompBench)**: 생성 이미지에 대해 BLIP VQA로 "attribute X인 object Y가 있는가"를 묻고 그 확률로 채점한다. Color/Shape/Texture/Spatial/Complex 카테고리별로 300개 프롬프트가 있다. 객체 누락만 따로 재는 지표가 아니라는 점에 주의해야 한다.

## 2) 무엇을 문제로 보았나 (관찰한 증상 · 분석한 원인)
**증상**
- SDXL 같은 최신 모델도 "a brown boat and a blue cat" 정도의 2-객체 프롬프트에서 고양이를 빼먹거나 색을 바꿔 붙인다(Fig. 1). 프롬프트가 복잡해질수록 실패가 더 잦고 형태도 다양해진다고 주장한다. 다만 길이에 따른 정량 수치는 제시하지 않았다.
- **위치 편향(Fig. 2a, 이 논문의 핵심 관찰)**: CC-500의 "a ⟨attr1⟩ ⟨obj1⟩ and a ⟨attr2⟩ ⟨obj2⟩" 프롬프트로 생성한 이미지 중 **두 object가 모두 나온 220장**만 남기고, 각 object의 attribute를 사람이 직접 분류했다. 어떤 모델로 생성했는지는 본문에 명시되어 있지 않다(문맥상 SDXL로 추정).

| object 위치 | Aligned | Misaligned(다른 attr) | **Missing(attribute 누락)** |
|---|---|---|---|
| obj1 (앞) | 77.7% | 9.1% | **13.2%** |
| obj2 (뒤) | 44.1% | 22.7% | **33.2%** |

  → 뒤쪽 pair의 attribute 누락률이 앞쪽의 약 2.5배(13.2% → 33.2%)이고, misbinding은 약 2.5배(9.1% → 22.7%)다. 정상 정렬은 77.7%에서 44.1%로 떨어진다.
  **주의**: 이 표는 *object가 둘 다 있는* 조건에서의 **attribute 누락**이다. **object 자체의 위치별 누락률은 이 논문이 직접 측정하지 않았다.** 논문은 그것을 선행 연구 [5] Chen et al. 2024, "A Cat Is A Cat (Not A Dog!): Unraveling Information Mix-ups in Text-to-Image Encoders through Causal Analysis and Embedding Optimization"(arXiv 2410.00321)의 결과("뒤에 언급된 object가 더 잘 사라진다")로 인용만 한다. 위치 효과와 object 누락을 직접 다룬 근거가 필요하면 [5]를 따로 읽어야 한다.

**원인 분석(text encoder 내부 신호)**
- **뒤쪽 개념일수록 entropy가 높다(Fig. 2b)**: 같은 프롬프트에서 두 pair의 순서를 바꾸면 entropy 순위도 같이 뒤집힌다. Original 기준 attr1&obj1 ≈ 0.9537, attr2&obj2 ≈ 0.9552이고, Swapped에서는 반대가 된다(그래프 판독값). 즉 entropy 차이는 단어 자체가 아니라 *위치*를 따라간다. 3-pair 합성 프롬프트에서도 First < Second < Third 순서가 유지된다(Attribute 약 0.9521/0.9536/0.9546, Object 약 0.9546/0.9551/0.9556, 판독값).
- **어휘 교란 통제**: CC-500에는 특정 위치에 주로 나오는 명사가 있다. 그래서 두 위치 모두에 나오는 명사만 골라 앞/뒤 entropy를 짝지어 비교했다. CLIP-G에서 뒤 위치 entropy가 평균 **+0.0033** 높았고, **paired effect size d_z = 1.08**, **p = 1.9×10⁻⁹**였다.
- **entropy가 높을수록 실패한다(Fig. 2c)**: ⟨attr2⟩ entropy는 Aligned ≈ 0.9557보다 Misaligned/Missing ≈ 0.9565가 높다. ⟨obj2⟩ entropy는 Present ≈ 0.9543 < Mixed ≈ 0.9547 < Missing ≈ 0.9554 순이다(판독값). 프롬프트 수준에서도 "둘 다 있음 → 하나만 → 둘 다 없음"으로 갈수록 평균 entropy가 오르고, entropy 분위가 높을수록 concept-loss 빈도가 "substantially" 오른다고 한다. 다만 분위별 수치는 supplementary로 미뤘다. 저자들도 이 신호를 discrete predictor가 아니라 "graded signal"이라고 선을 긋는다.
- **인과 개입(norm 보존 회전)**: 개념 embedding을 c_i와 µ̂가 이루는 평면 안에서 크기를 유지한 채 ‖c′−c‖ = α‖c‖만큼 회전시켰다.

| 개입 | concept loss rate |
|---|---|
| 원본 | 27.3% |
| µ̂ 쪽으로 회전(entropy↑ 방향) | **35.7%** (+8.4%p) |
| µ̂ 반대로 회전 | **22.3%** (−5.0%p) |
| 같은 크기 랜덤 직교 회전 | 변화 미미(수치 미제시) |

  → 공통 방향 µ̂ 쪽으로 정렬되는 것이 누락의 *원인*이라는 근거로 제시된다. α 값, 모델, 표본 수는 본문에 없다.
- **concept confusion의 원인 신호(L0 attention, Fig. 3)**:
  - 최종 embedding 기준 cosine similarity와 L2 distance로는 related pair와 unrelated pair의 분포가 크게 겹친다(Fig. 3b).
  - attribute token의 key를 layer별로 masking하면 **L0에서만** attribute가 크게 사라진다(Fig. 3a, L0/L3/L6/L9 비교).
  - L0에서 function word를 masking하면 conditioning 변위는 8.4배 크지만 target loss는 **+1.5%p**에 그친다. target attribute를 masking하면 변위는 작아도 **+58.5%p**다. middle layer에서 같은 masking을 하면 **+1.0%p**다.
  - L0 attention으로 related pair와 unrelated pair를 구분한 AUC: 원시값 **0.980 (CLIP-L) / 0.965 (CLIP-G)**. token 거리를 회귀로 제거하면 **0.648 / 0.624**. 거리를 맞춘 비교에서는 **0.634 / 0.658**이다. → 상당 부분이 "가까운 token끼리 attention이 크다"는 거리 효과이고, 거리를 넘는 관계 정보는 약하다(AUC 0.62~0.66).

## 3) 방법 (Method)
전체 흐름(Fig. 4a): 프롬프트를 Stanza로 parsing해 attribute–object 쌍을 찾는다 → CLIP text encoder로 embedding과 L0 attention map을 얻는다 → **AEP → IEB 순서로 embedding을 딱 한 번 업데이트**한다 → 고친 embedding을 frozen T2I 모델에 넣는다. 최적화, 학습, sampling 중 개입이 없다(Table 1의 "Opt-free ✓").

**AEP (Adaptive Embedding Preservation), concept loss 대응**
1. **Decorrelation**: causal attention 때문에 뒤 개념에 앞 개념 정보가 섞여 있다고 보고, k번째 개념에서 앞 개념들의 평균 embedding에 상수 C를 곱해 뺀다. 식은 c̄_k = c_k − (C/(k−1)) Σ_{j<k} c_j다.
2. pair별 행렬 X = [c_k^attr, c_k^obj, c_0^EOT, …, c_{N−|P|−2}^EOT]를 만들고 SVD로 X = UΣVᵀ를 구한다.
3. **Entropy-aware boost (Eq. 2)**: σ̂_i = σ_i · δ · exp(γ σ_i H̃)로 재조정한다. 여기서 H̃는 X에 들어간 embedding들의 평균 token entropy다. entropy가 높은(=뒤쪽, 누락 위험이 큰) 개념일수록 큰 singular value가 더 크게 증폭된다. γ, δ > 0.
4. **Proposition 1**: g가 양수이고 증가함수이면 f(σ)=σg(σ)로 재조정한 분포가 원 분포를 majorize한다. 그래서 Shannon entropy와 erank가 줄어든다(spectrum 집중이 보장됨). 실측 erank는 CLIP-L 4.28 → 3.92, CLIP-G 12.73 → 11.67(−8~13%)이고, Eq. 1 token entropy가 같은 방향으로 움직인 개념이 99.9%였다.

**IEB (Interpolation–Extrapolation Binding), concept confusion 대응**
- Related pair(attr_i, obj_j)는 서로 당긴다(Eq. 3): c̃_i = (1−α_{ij})c_i + α_{ij}c_j이고 c̃_j도 대칭으로 바뀐다. **α_{ij} = λ_int (1 − A_{ij})**이므로 L0 attention이 약한(binding이 약한) 쌍일수록 더 세게 당긴다.
- Unrelated pair(k, l)는 서로 민다(Eq. 4): c̃_k = (1+β_{kl})c_k − β_{kl}c_l이다. **β_{kl} = λ_ext A_{kl}**이므로 잘못 붙을 위험이 큰(attention이 큰) unrelated 쌍일수록 더 세게 민다.

**구현 메모**: L0 attention은 head 평균이다. 하이퍼파라미터 γ, δ, C, λ_int, λ_ext의 실제 값은 본문에 없다(supplementary로 추정). SD3.5는 CLIP-L, CLIP-G와 T5-XXL을 함께 쓰는데, T5 embedding을 어떻게 처리했는지(그대로 두는지)는 본문에 명시되어 있지 않다.

## 5) Challenge를 걸 부분
**비판적 검토**
1. **"위치 → 누락"의 주 증거가 object가 아니라 attribute에 관한 것이다.** Fig. 2a는 두 object가 모두 있는 220장으로 조건화한 attribute 표다. object 누락의 위치 효과는 [5]를 인용만 한다. 게다가 이렇게 조건화하면 생존 편향(selection bias)이 생긴다. obj2가 빠진 이미지가 제외되어 있으니 뒤쪽 실패율은 오히려 과소추정되었을 수 있다. 생성 모델, 원래 이미지 수, 주석자 수, 주석자 간 일치도도 없다.
2. **효과 크기의 실질성 문제**: entropy 차이가 0.0033이다(값이 0.95대에 몰려 있음). d_z가 큰 것은 쌍별 분산이 작기 때문이다. 이 차이가 이미지 수준 누락을 얼마나 *예측*하는지(AUROC, calibration)는 본문에 없고 supplementary로 미뤘다. 저자들 스스로 "graded signal rather than discrete prediction"이라고 한다.
3. **위치와 causal 문맥 길이가 분리되지 않았다.** 뒤 token의 entropy가 높은 이유가 (a) 절대 위치 임베딩인지, (b) causal attention으로 앞 개념 정보가 섞인 결과인지, (c) "and a" 같은 접속 구조 때문인지 구분하지 않았다. neutral filler를 앞에 붙이거나("a photo of …"), 위치를 고정한 채 앞 문맥을 바꾸는 식의 통제가 없다. AEP의 decorrelation(앞 개념 평균 빼기)은 (b)를 가정하지만, 이 가정 자체는 검증하지 않았다.
4. **짧은 프롬프트에만 적용했다.** 분석은 2~3 pair, 평가는 T2I-CompBench(대부분 2 object)다. 본문은 "longer and syntactically more complex prompts에도 적용 가능"하다고 말하지만 실험이 없다. CLIP 77-token 한계로 잘리는 경우, 5개 이상 object가 나오는 dense prompt, 관계절이나 수량사가 있는 문장은 다루지 않았다. Stanza parsing이 틀릴 때 어떻게 되는지도 분석하지 않았다.
5. **평가 지표가 누락을 직접 재지 않는다.** BLIP-VQA는 object 존재와 attribute를 섞어 한 확률로 채점한다. 누락을 직접 재려면 GenEval 같은 detector 기반 object presence, counting, 사람 평가가 필요한데 본문에 없다(supplementary에 "다른 지표"가 있다고만 함). 부작용으로 **원치 않는 object, 중복, artifact가 늘어나는지**도 재지 않았다. singular value 증폭과 extrapolation은 embedding norm과 방향을 크게 바꾸므로 image quality(FID/aesthetic)나 diversity를 확인해야 한다.
6. **SD3.5 결과가 약하고 T5 처리가 불명확하다.** MM-DiT에서 T5 경로가 주된 텍스트 조건일 수 있는데, CLIP만 고친 효과가 +0.01 수준이다. FLUX(T5 + CLIP pooled), PixArt(T5), LLM-encoder 계열(Qwen-Image 등)처럼 causal CLIP이 없는 모델로 일반화할 수 있는지는 미지수다. "위치 편향이 causal CLIP에서 온다"는 가설이 맞다면 bidirectional T5 모델에서는 위치 효과가 약해야 한다. 이를 확인하면 가설을 반증할 수 있는 좋은 실험이 된다.
7. **Ablation과 통계가 약하다.** SD3.5-L에서만 했고, AEP+IEB가 IEB 단독보다 Color/Texture/Complex에서 나쁘다. 하이퍼파라미터 값과 민감도를 보고하지 않았고, seed 분산이나 유의성 검정도 없다.
8. **L0 attention 신호가 약하다.** 거리 효과를 통제하면 AUC가 0.62~0.66이다. IEB의 α와 β가 사실상 "token 거리" 함수로 동작할 수 있다. 같은 거리의 반대 binding("a red X and a blue Y"에서 blue–X)은 구분력이 낮을 것이다.

**후속 연구 아이디어 (사용자 관심사 연결)**
1. **긴/밀집 프롬프트에서 object 단위 위치–누락 곡선과 entropy 예측력 검증**: N = 2, 4, 6, 8, 10+ object 프롬프트를 만들고, 각 순서를 Latin-square로 permutation해 어휘와 위치를 분리한다. GroundingDINO/OWL-v2로 object별 presence를 판정해 *위치별 object 누락률*을 직접 잰다. 이 논문에 없는 핵심 수치다. 같은 데이터에서 TIE의 token entropy가 object 누락을 얼마나 예측하는지(AUROC, 분위별 누락률)를 재고, 77-token 경계 근처에서 entropy와 누락이 급변하는지 본다. 인코더별로 비교(SDXL[CLIP], SD3.5[CLIP+T5], FLUX, PixArt-Σ[T5], LLM-encoder 모델)하면 "causal CLIP 때문"이라는 가설을 검증할 수 있다. 위치 효과가 T5/LLM 인코더에서도 남는다면 원인은 이미지 모델 쪽(joint attention, 학습 캡션의 앞쪽 주제 편향)에 있다는 증거가 된다.
2. **위치 공정성을 위한 budget형 AEP와 누락 trade-off 분석**: AEP는 뒤쪽 개념을 키우지만, 이미지 공간은 제한되어 있으므로 *앞쪽 개념이 대신 빠지는* zero-sum 효과가 있을 수 있다. 앞/뒤 각각의 누락률 변화를 따로 보고하고(파레토 곡선), "모든 위치 누락률의 최댓값 최소화" 같은 position-fair 목적함수로 증폭 계수를 정한다. 대안으로 embedding 편집 대신 **entropy가 높은 개념을 앞으로 재배치**하는 prompt reordering이나, 개념별 짧은 sub-prompt 임베딩을 합성하는 방식과 비교해, 위치 편향을 고치는 가장 싼 방법이 무엇인지 확인한다.
3. **상충 요구(conflicting requirements)를 L0 attention과 entropy로 탐지하고 해소하기**: "a red apple … everything is blue", "an empty room with a chair", "a cat without ears", 상호 배타적 공간 관계처럼 서로 부딪히는 제약에서 어떤 제약이 이기는지 위치별로 측정한다. 가설은 "뒤에 온 제약이 더 자주 진다"이다. IEB의 extrapolation(unrelated pair 밀어내기)을 "충돌 쌍"에 적용하면 충돌이 해소되는지, 아니면 둘 다 약해지는지 본다. 또 L0 attention이나 entropy로 생성 *전에* 충돌을 탐지하는 분류기를 만들 수 있는지 시험한다. 충돌 쌍의 attention 패턴이 related/unrelated 쌍과 구분되는지가 관건이다.
4. **요청 외 object(unrequested objects)와 부작용 측정**: TIE처럼 singular value를 증폭하거나 EOT token을 조작하는 방법이 (a) 같은 object 중복(count 증가), (b) 프롬프트에 없는 연상 object(예: "boat" → 물, 사람), (c) 두 object 혼합(Fig. 1d 유형)을 늘리는지 잰다. open-vocabulary detector로 "탐지된 object − 요청된 object" 집합을 세면 된다. 방법이 누락을 줄이는 대신 hallucinated object를 늘리는 precision–recall trade-off를 객체 수준에서 정량화하면, 누락 연구 전반에서 쓸 수 있는 평가 프로토콜이 된다.
5. **(보너스) 인과 메커니즘 정밀화**: 이 논문의 µ̂ 회전 실험(27.3% → 35.7% / 22.3%)을 위치별로 다시 해 본다. "뒤쪽 개념이 µ̂에 더 가까워서 빠진다"를 직접 검증하는 것이다. 예를 들어 뒤 개념만 µ̂ 반대 방향으로 회전했을 때 앞/뒤 누락 격차(13.2% vs 33.2% 유형)가 얼마나 줄어드는지 보면, 위치 효과 중 embedding geometry로 설명되는 비율을 추정할 수 있다.
